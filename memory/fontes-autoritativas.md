# Fontes autoritativas

Ficção. O que esta base aceita como fonte, e o que ela ignora.

## Ordem

1. `Agent.md`, para pergunta simples, dentro do que as quatro seções dizem.
2. `Verdade compilada` do tema em `memory/`, para o estado atual.
3. `memory/ledger-decisoes.md`, para saber se uma regra ainda vale.
4. `Trilha` do tema, para ver quando o estado mudou.
5. `memory/diario/`, para o que ocorreu num dia específico.
6. `memory/licoes.md` e `memory/regras-fixas.md`, para não repetir erro e para o modo de responder.

`friday-context/` não é fonte vencedora. É um resumo. Se brigar com `memory/`, fica `memory/`.

## O que não entra

- Qualquer coisa fora deste repositório.
- Roteiro, fala pronta de filme ou desfecho de cinema. Esta é uma continuidade alternativa, e o presente é o cotidiano.
- Dado de pessoa real, contato, documento, conta ou endereço.
- Suposição para tapar buraco. A resposta certa é que não consta.
- A luva de voz deste teste. Ela lê a memória; não é um projeto da oficina do Tony.

## Figuras

Pepper Potts, Morgan Stark, Happy Hogan, James Rhodes e Peter Parker são o círculo fictício desta demonstração. Nina Vasquez, Omar Diallo e a dra. Renata Kline foram inventadas para a oficina e a saúde da empresa. Não representam pessoas reais.
