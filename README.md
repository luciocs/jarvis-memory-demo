# Memória fictícia — exemplo padrão do Sarandip Server casa

Este repositório é a memória de exemplo padrão do Sarandip Server casa. É memória fictícia, no estilo do MCU. Não é uma pessoa real.

This repository is the default example memory of Sarandip Server casa. It is fictional MCU-style memory, not a real person.

Tony Stark segue vivo nesta continuidade alternativa, num presente cotidiano: Pepper Potts, Morgan Stark, a Stark Industries e a oficina. Onde isso diverge de um desfecho de filme, o rótulo é ficção. Não há dados de nenhuma pessoa real.

Aviso: este repositório é público de propósito. Nunca deve receber dados pessoais reais nem segredos.

Warning: this repository is public on purpose. It must never receive real personal data or secrets.

## Como a luva lê

A leitura rápida usa só `Agent.md`, na raiz, com quatro títulos de nível 2, nesta ordem e com estes nomes:

- `## Quem sou`
- `## Família`
- `## Tom e formato`
- `## Perfil resumido`

Essas seções cabem em cerca de 1200 caracteres, abaixo do corte de 1400. Não use outro nível de título no lugar desses quatro. Não coloque arroba, contato, documento ou segredo nesse arquivo.

## Camadas

- `Agent.md` é o contexto curto (N3).
- `memory/` guarda os temas (N2): estado atual em `Verdade compilada`, evidência datada em `Trilha`.
- `memory/diario/` guarda o dia cru (N1).
- `friday-context/` é um resumo paralelo, mais curto, dos mesmos temas. Não vence o arquivo em `memory/`.
- `secrets/README.md` só registra que esta demonstração não contém segredos.

Figura inventada para a oficina, sem correspondente real pretendido: Nina Vasquez (bancada), Omar Diallo (materiais) e a dra. Renata Kline (médica da empresa). JARVIS e FRIDAY, aqui, são ferramentas fictícias da oficina. A luva deste teste não é uma invenção canônica do Tony.
